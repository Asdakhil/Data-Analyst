# Data Analyst Experiments

Small public collection of Python, Streamlit, Altair, and notebook experiments for financial analytics and PDF/LLM workflows.

## Current Files

- `FS_Charting_RCLCO.py`: Streamlit/Altair financial charting app for asset comparisons.
- `FS_Charting.ipynb`: notebook experiment for financial statement charting.
- `PDF_Query_LLM.ipynb`: notebook experiment for querying PDFs with LLM tooling.
- `PDF_Con_Excel`: Python script for PDF/Excel workflow, currently missing a `.py` extension.
- `FANG_UPDate`: Python script, currently missing a `.py` extension.
- `FANG.PY_DA_Streamlit`: Streamlit app script, currently missing a conventional `.py` extension.

## Recommended Cleanup

This repo should either be archived as an old experiment or cleaned into a public portfolio repo.

If cleaning it up:

1. Rename extensionless Python files to `.py`.
2. Remove hardcoded local paths such as `/Users/ahmedshaker/Downloads/...`.
3. Add sample data or document where users should place their own data.
4. Add `requirements.txt`.
5. Add a simple run command for each Streamlit app.
