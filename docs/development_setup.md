# Development Setup

## Recommended Local Tools

- Git and GitHub authentication
- Python 3.11+ with `venv`
- Jupyter for notebook work
- Streamlit for app previews

## Suggested Setup

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install pandas streamlit altair openpyxl jupyter
```

A future cleanup should add a checked-in `requirements.txt`.
